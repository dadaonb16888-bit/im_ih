# Phase 1 后续：评分证据与真实研究案例

2026-10-13。继续依据根目录两份最高优先级规范，范围仅Event Layer。

## 分析与问题

现有数值引擎已具备评分能力，但实库18个Parent未完成正式评分。8条AI卡缺少逐项数值理由；部分事件只有日期，不能生成精确衰减时间。来源可靠与方向判断可靠不是同一件事，不能直接将文字High或官方来源自动换成高数值方向置信度。

## 本轮实施

1. 增加评分依据契约：每项数值/来源/参考时间分别记录value、reason、source_ids和rubric版本；校验引用、读取状态和时间与原始来源一致，允许明确未知。
2. 新增独立研究评分投影，只有具有评分依据的新卡进入预览；不回写Parent方向，不生成市场State，不参与正式Dominant排序。旧卡继续可读。
3. 来源发布时间只用作标明的参考衰减时间，不能改写成已核实的全局最早EventTime。日期级来源没有精确分数；有其他组件时可展示不含Freshness的基础强度。
4. 先复核新质生产力政策和公募规则两张卡。官方基线、条款与可读取的指数事实表形成新证据；未知相对受益保持未知。数值为Codex的可解释研究刻度，不是校准胜率。
5. 增加CLI/API和工作台展示、事务/引用/时间/未知回归测试，更新同一草稿PR。

## 文件与数据

新增event_engine/score_evidence.py；修改ai_research.py、scoring.py、manage.py、workbench.py和工作台展示。评分依据保存在现有AI判读JSON追加账本，不改旧记录，也不增加交易模块。

## 验证与风险

禁止把未读来源支持为已知事实、把日期补成零点、把参考时间伪装成全局首发；禁止用分数绕过正式因果审核。全量回归、旧记录保留和浏览器展示检查完成后更新PR。研究评分与正式Alpha始终分别输出。
