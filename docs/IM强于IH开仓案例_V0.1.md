# IM强于IH：假设案例 V0.1

日期：2026-10-16。所有数值为合成算例，不是实时行情、真实账户、历史回测或下单建议。对应[规则草案](IM强于IH开仓规则草案_V0.1.md)，不写入Event/State/交易账本。

## 1. 突破与回落

为便于阅读，用比值Q=M_IM/M_IH展示，X=ln(Q)。由于ln严格递增，本例高点比较与草案一致。此前5根完整同步相对K线高点为2.3300、2.3310、2.3320、2.3315、2.3325，本次突破位为B_Q=2.3325。

| 情形 | 纸面处理 |
|---|---|
| 当前完整K线收盘Q=2.3333，t0、数据、报价和预算等条件均满足 | 只产生候选，等待确认后合格报价；不保证成交 |
| 收盘Q=2.3325 | 等于阈值，不触发 |
| 盘中最高2.3340，收盘2.3320 | 收盘未突破，不触发 |
| 当前完整K线早于t0开始 | 不作本假设触发 |
| 只有4根合格前序K线，或中间缺1分钟 | 等待，不补造第5根 |
| 只有两腿各自分钟OHLC，没有同步相对高点 | 本高点模型输入不足；不拼两腿极值 |
| 同一候选键重复到达，或组合仍在持有 | 不再发起新尝试 |
| 突破后下单前报价超时、跨月配对、价差超限或风险配置缺失 | 不开仓 |
| 已持有，后续完整K线收盘Q=2.3318 | 跌回冻结突破位下，产生整组退出意图 |
| 完整K线尚未结束，但估计可平仓净亏损达到现金风险上限 | 不等收盘，优先退出/恢复；不保证实际损失止于该上限 |
| 只成交IM，IH尚未完成 | 进入恢复，停止加仓和新尝试，核委托/敞口；不能称为组合已建立 |
| 第3次实际成交尝试已经用完 | 同一判断版本停止新尝试 |

“全部条件满足”是用来检查逻辑的假设，不说明真实系统已通过事件或市场资格；entry_allowed依旧false。

## 2. 时间标记

假设触发K线为[10:15,10:16)，信号处理完成于10:16:00.200。10:16:00.100报价早于信号可用时刻，不拿来假设成交。后续报价还要核同步、价差、深度和有效期。即使两个分钟的边界价格相同，也不能把已知收盘后决定的订单倒填为先前成交。

## 3. 手数与预算

假设入场价IM=7000、IH=3000，基础组为多2IM、空3IH：

| 项目 | 数值 |
|---|---:|
| IM名义金额 | 2×7000×200＝2,800,000元 |
| IH名义金额 | 3×3000×300＝2,700,000元 |
| 残余名义多头 | 100,000元 |
| 以较大单边金额为分母的偏差 | 100,000÷2,800,000≈3.5714% |

若纸面容忍度2%，拒绝该组；若容忍度4%，只说明金额条件通过，还须检查成本、风险和资金。2%和4%均为例子，不是策略建议。

9IM:14IH在这组价格下各为1260万元，金额相等但规模更大；超预算时应放弃，不能以“更中性”为理由扩大规模。

另一个独立预算算例：风险预算R=5万元，一组预先列出的压力情景最大净损失估计1.8万元，风险最多2组；保证金余量若只允许1组，总量最多1组。若连1组也不满足，结果为0组。情景外损失仍可能更大。

## 4. 两腿盈亏核算

以下沿用多2IM@7000、空3IH@3000，先展示不含成本的毛盈亏：

| 后续价格 | IM变化 / IH变化 | IM腿PnL | IH腿PnL | 合计 |
|---|---|---:|---:|---:|
| IM7070、IH3015 | +1% / +0.5% | +28,000 | −13,500 | +14,500元 |
| IM6930、IH2940 | −1% / −2% | −28,000 | +54,000 | +26,000元 |
| IM7070、IH3030 | +1% / +1% | +28,000 | −27,000 | +1,000元 |

第三行两腿涨幅相同仍有1000元毛收益，来自残余10万元多头的共同市场上涨；不能当成相对方向正确或无风险Alpha。净收益还须减实际两腿手续费、平今、执行和恢复成本。相对价突破也不保证最终盈利。
