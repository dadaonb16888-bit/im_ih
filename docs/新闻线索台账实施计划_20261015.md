# 新闻线索台账实施计划

当前问题：来源扫描的标题链接存于审计附件，未读线索没有进入工作台；入口单次截取35条也不能证明完整覆盖。现有原始信息、三轮初筛、Parent与AI判读保持原流程。

增量实现：新增event_engine/discovery.py及测试；修改database/schema.sql、engine.py的追加保护、collection.py报告、manage.py命令和dashboard/collection.js展示。新增discovery_leads、discovery_resolutions、discovery_runs三张追加表。可信本地包一次导入发现和处理记录，实际入库时刻为known_at；历史扫描时间只是证据注记。

线索只保存标题、URL、登记来源、发现入口与未核实日期线索。状态为待读、读取受阻、已关联原文、已排除。关联必须指向当时可见、URL一致、已读取或部分读取的原始资料；部分读取仍计缺口。修订追加新处理记录，并检查前版本，禁止覆盖和陈旧处理。标题不生成事实、三轮初筛或方向。排除必须解释原因并保留证据。

工作台增加只读线索页、状态筛选及来源链接；未处理和部分读取计入批次缺口。兼容无此台账的旧批次，不改变旧包格式。旧扫描审计中的链接补录使用当前时刻，不倒填、不声称已收齐分页。

风险与验证：来源/批次引用、URL安全、相同入口链接去重、时点可见性、原文关联、陈旧更新、整包回滚、重放幂等、旧库升级与追加保护。全部测试及页面核查后同步草稿分支。新消息核对如执行，采用新截止或独立标注，不扩写旧窗口。
