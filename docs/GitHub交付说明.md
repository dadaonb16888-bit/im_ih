## 在其他电脑运行

需要Python 3.10或更新版本。程序使用标准库，无需安装第三方Python依赖。在仓库根目录执行：

```text
python workbench.py
```

然后访问 http://127.0.0.1:8766/ 。当前知识库快照位于`database/events.sqlite3`，首次运行即可查看现有成果。程序仅监听本机地址。

执行检查：

```text
python -m unittest discover -s tests -v
```

## 成果与数据边界

- `data/events`与`data/exported_research`保留来源CSV和研究记录；历史标签不代表方向已验证。
- `data/historical_audit_v1.json`及`docs/首轮历史事件审核.md`记录事实核查、时间精度、相对方向假设和证据缺口。
- `database/events.sqlite3`保存本次提交时的知识库快照。工作台后续追加的本地记录需要再次提交才会同步到GitHub。
- 数据库备份、缓存、虚拟环境、日志和环境配置不进入版本库。文档中提到的本地备份仅存在原电脑。
- 早期迁移命令引用原电脑的`../analysis/ih_im_event_research`。该目录未包含在本仓库；已迁移成果保存在数据库和导出记录中，运行工作台及测试不依赖该外部目录。
- 来源聊天链接可能需要原账号权限；项目启动包与读取范围说明已保留在仓库文档中。
