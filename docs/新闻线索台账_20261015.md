# 新闻线索台账

本轮先补收集流程：发现的链接必须留痕，未读不能冒充事实。新增三张追加表与可信本地导入，旧数据库首次打开时自动追加结构，原有事件、原始资料、筛选、研究和页面保留。

## 处理流程

发现入口/标题 → 保存未核线索 → Codex短判断是否值得读取 → 必要时读取原文并关联信息 → 三轮初筛 → 通过项按Parent归并深查。明显导航等可以直接解释并排除，不要求把所有候选正文读完。标题不提供评分、方向或市场确认，候选数量不等于新闻数量。

Pending为尚待处理，Blocked为读取受阻，Linked为已关联同URL且当时可见的已读/部分读取资料，Excluded为有理由及证据的排除。部分读取虽然已关联，仍计未解决缺口。关联不等于通过初筛。原始发布时间与日期线索分开；URL中的日期不当作已核时间。

每次处理追加新ID并引用最新前次处理ID，旧版本不覆盖；新发现不倒填known_at。包的已存在ID只允许完全相同内容重放。正文URL不一致、未读或未来才入库的材料不能用于关闭线索。来源必须在批次冻结清单中，同批同入口的规范化URL不得重复登记；不同来源发现同一链接仍保留各自来源，未自动按标题合并事件。
