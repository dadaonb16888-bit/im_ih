## 2. 已确认的问题

| 问题 | 实际观察 | 处理要求 |
|---|---|---|
| 没有报价 | 187份均为分钟级数据，未含bid/ask字段 | 原同步报价模型仍缺输入；不能用分钟OHLC替代逐笔同步 |
| 标签混用 | IM拼接1001天符合09:30起始网格，23天符合09:31结束网格；IH分别2489天、30天，另3天不完整/其他 | 按供数路径逐段核对bar_start/end；网格只是诊断，不能机械平移一分钟 |
| 分钟标签缺口 | 两拼接文件在1022个共同有记录的日期上，交集245186、并集245298；112个单边标签，交并比99.9543% | 必须看逐日缺口，不能用高比例宣布完整或同步；不前向填补行情 |
| 整日单边缺失 | IM有2026-08-06、2026-09-10，IH拼接没有这两日记录 | 核对具体IH合约与拼接选择；未修复前隔离对应日期 |
| 原始缓存异常 | 48行OHLC非有限；47行同时无法解析时间。独立CSV检查发现47行含NUL且记录不完整 | 单独隔离并追溯供数；不是48个零价，也不能将空值补成有效价格 |
| 主连时钟可疑 | KQ.m两份均在01/02/03/05/06小时；按原标签与对应拼接交集0，试加8小时各匹配10000标签 | +8小时仅为诊断线索，来源和时区未经确认，不执行转换；主连止于6月18日 |
| 副本不同 | 旧IH和IM副本止于7月21日，冲突IM副本止于7月17日；主目录拼接止于10月15日 | 不混用、不删除，主目录为本轮基准 |
| 持仓量缺失 | IM拼接open_oi缺235440/245760行，close_oi不缺；IH open_oi缺7672/605204行 | 不能据open_oi直接算完整持仓变化；零成交与缺失分开 |

原始具体合约时间戳重复额外行合计0；连续共同有效时间标签上合约月份不一致0。它们只通过相应检查，不证明完整日历、供数时区、报价同步或真实可成交。起始网格假设为09:30–11:29、13:00–14:59；结束网格为09:31–11:30、13:01–15:00，均未当作已核官方bar定义。

更新工具的已读代码显示两种来源处理：Sina/akshare路径保留来源时间，TqSdk路径显式加8小时；这不证明任一具体行的原供数方。日历拼接按到期月规则选原始contract，不是按成交量/持仓量选主力，未见价格复权；假期到期规则仍需独立核对。没有执行下载、刷新或修复脚本。
