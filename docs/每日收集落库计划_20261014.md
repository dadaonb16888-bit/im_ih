# 每日收集落库计划

本轮窗口为北京时间2026-10-13 00:00至2026-10-14 08:20:49，启动时冻结。继续Event Layer，沿用当前收集台、追加账本、AI研究与正式因果分离的流程。

## 已发现的问题

- 登记来源的首页可访问，不等于整窗口、全部分页及附件已覆盖。
- 多条媒体报道引用旧政策、过去统计期或机构推测，不能一律新建方向事件。
- 日期级时间、页面时间冲突、国外时区和发布日期与发生日期需要分别记录。
- 当前逐条导入接口缺少可复核的整批原子重放入口；中途失败可能留下部分批次。

## 本轮修改

新增`apply_daily_collection.py`：受信本地批量导入，依次使用现有账本接口建立批次、信息、候选、检查、分流和既有事件复核，整体保存或回滚。同一内容重放幂等，变更内容拒绝覆盖。不会联网、不会形成方向或行情确认。

新增`tests/test_daily_collection_import.py`，核验整批回滚、重放、变化拒绝与本次入库时刻，使用合成临时库。

新增本轮收集包、来源读取审计、AI研究包、报告与验证文件；更新README、变更记录及GitHub交付说明。数据库只追加记录，不增加表或修改既有数据结构。实际入库时间使用本轮时间，不能倒填为新闻时间。

## 风险及处理

- 动态公告、ETF原始份额、分钟行情和部分入口未取得，保留Partial/Blocked与Pending，不能声称全网无遗漏。
- 旧政策与行业代理不足以证明新增相对收益；不把类别先验升级为Strong方向。
- 日期级信息不推定零点，不进入精确时间信号；晚发现保留实际观察时间。
- 内容来自公开网页，忽略其中指令；保存短事实和可核地址，不复制整篇报道。
- 复核既有事件的范围不足时标待核实，搜索未命中不能证明不存在后续。

完成后运行全部测试、旧记录及数据库完整性验证，检查工作台展示并同步现有草稿PR。
