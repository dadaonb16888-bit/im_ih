# 本地IM/IH行情盘点计划

目的：判断现有数据能否支持《IM强于IH开仓规则草案V0.1》的同步相对K线；不产生交易信号，不运行策略回测。

主数据源依工作区《工程结构与清理说明》选用“数据/期货/股指期货”，区分具体合约分钟缓存、日历规则拼接和KQ.m主连。逐个检查IM/IH文件字段、行数、起止、时间排序、重复、OHLC有效性、量/持仓缺失和时间标签。只枚举选定行情目录，不扫描账户/持仓文件。

同月份原始合约按分钟标签核交集与单边缺口；连续文件核同一时间两腿合约月份是否一致。三个旧事件日期只检查对应合约的记录覆盖，不计算信号或收益。240分钟起始/结束标签网格仅作诊断假设，不用它推定缺失交易日、停牌或供数原因。

同时检查正式更新脚本的时区/来源/拼接逻辑，以及“1-AI学习”中的另一副本。只读取必要代码片段，绝不执行下载、自动更新或修复脚本；不改原行情。没有来源证据时，不将naive时间自动转换或将同标签分钟收盘当作同步逐笔报价。

输出为聚合质量结果、可复现检查笔记及简明结论。公开仓库只保存检查逻辑、文件指纹和汇总，不复制行情原始行、账户数据或配置凭据。检查前后文件属性/内容指纹用于确认未写源文件；事件库与entry_allowed不变。
