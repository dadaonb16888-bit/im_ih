# 基线复核与产品暴露：实施计划

当前两张V3卡已具逐项对照，但研发强化仅对2023税率基线，未查2024中央政策意向；先用后付仍缺基线；公募成立门槛主要依发布方比较，真实产品投向尚未补。用户授权继续事件解释，由Codex判断并追加修订。

本轮先读取较早政策原文、2014公募旧规及事件发生前公开的基金报告。复核后才生成V4，不补造首发、市场确认或净流量。旧卡不改写。若反证削弱IM相对优势，允许撤回研究方向；未知不改为中性或零分。

产品报告同时记录报告期末与公开日期，不能把6月末组合当作10月9日实时持仓。产品组合依据与公司业务分开，拟在原可选impact_analysis.exposure_type中增PortfolioDisclosure枚举和中文展示，沿用原日期及引用校验，不加评分因子或新数据库表。测试只验证日期与类型边界，再以临时库核研究包、实际库追加及旧记录保留、工作台展示。

修改范围：impact_analysis.py、dashboard/app.js及相关边界测试；新增V4研究包、复核说明与验证快照。官方基金报告只定向阅读关键页，完整副本保存在本机审阅目录，仓库仅保存少量事实摘要及引用。来源不可读时如实记缺口，不伪装读取。
