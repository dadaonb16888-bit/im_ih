# 待核信息短核验：计划与预算

用户要求继续落实低成本的多轮筛选。本轮仅处理已有11条Watch，相关船舶和民航资料按主题共享核验，未触发的新材料不做企业及指数长分析。不是10月15日全窗口新闻采集，不改写原收集截止。

## 当前缺口与改动

初筛有停止理由，但没有可追溯的短核验问题、读取依据和再次核验条件。增量扩展既有筛选记录，允许可选follow_up，不新建表或重写系统；旧包及只读接口保持兼容。修改news_screening.py、初筛页和测试；新增短核验校验模块、研究包及本轮说明。

follow_up记录prior_screening_id、group_id、priority、question、evidence_source_ids、finding、next_trigger、outcome（WaitEvidence/Archive/Rescreen）。每个主题最多3个不同来源，只存简短结论，不输出Bias。引用须为本次已知信息且有明确读取状态；只有Read/Partial可支持已知发现，Unavailable保留失败记录。旧Watch须与最新筛选ID相符，禁止过时核验覆盖更新。

WaitEvidence仍Watch，Archive须由初筛得出Background；Rescreen只表示已经重筛，须有可读原文支持，不保证DeepReview。完整事实仍由Codex实际读原文判断，结构校验不能证明推理正确。新正式数据单独新增来源及初筛，旧日程不能伪装为已知数据。

## 实际核查顺序

先查已过发布时间的CPI，再短读资金报道和综合早报。对原文受阻的国债及地方计划只尝试明确原地址，不枚举替代网址。既有细分产业主题没有新触发则先等待，不继续逐家企业深查。每主题最多3个原文地址，本轮不超过12个；找到足够证据即停止，访问失败不反复重试。

若CPI原始数据可核，新增独立来源并重新筛选；满足三轮才建立候选并用现有AIResearch追加判读。没有事前预期和两指数净暴露，不强定方向、不写市场State或交易信号。

验证：过时筛选、未来或缺失引用、结果与去向不符、过量来源、短字段、回滚和旧包重放测试；全量测试、数据库旧行/完整性检查、HTTP及浏览器验证。实际知识时刻用10月15日写入时刻，不倒填到14日日程或数据发布时刻。
