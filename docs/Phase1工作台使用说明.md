# Phase 1工作台使用说明

## 已完成的功能

事件知识库、11个历史Parent导入、来源研究记录、原始信息池、资料关联、因果更新、市场状态、分周期候选输出和完整审计记录。工作台地址： http://127.0.0.1:8766/ 。

当前共18个Parent候选：7个近期候选、11个历史事件。原36条信息和16条来源标签来自本地资料及ChatGPT工程包；2026-10-11首轮历史原文核查另加入7条来源信息、3张审核记录及2条未完成审核的因果更新，共43条原始信息、19条研究与审核记录。市场状态表仍为空，正式方向尚未通过审核。本次联网核查是历史来源审核，不是前一天至当前的全量新闻收集。

## 日常录入

1. 点“新增信息”，填写原文标题、来源、链接、事实和核实情况。公开时间不确定可留空；首次发现时间自动记录为本次保存时间。
2. 在左侧选择已有Parent。如果是独立新机制，点“创建事件”；不因每篇报道重复建Parent。
3. 点“信息池”，将对应原始信息关联到选中的事件。关联资料本身不会自动改变方向。
4. 在“因果更新”中说明新增事实、与旧信息/预期的差异、传导链和反方解释。选择InformationGain；补齐渠道、方向、周期、独立性、相对影响、时间和失效条件。
5. 证据齐备时勾选“提交完整因果审核”。缺项会提示；没有把握可只保存尚未审核的更新。Low只记录重复或低增量，不能同时修订因果字段。
6. 在“市场状态”中记录判断方法和行情证据。默认勾选“仅保存为待验证研究假设”，这类记录只进入研究来源层；取消后才写正式State，并按证据与时间参与资格判断。

## 查看事件演化

“事件与来源”展示当前正式方向、初始方向、资格、缺口、来源标签和关联原文。新增“原文审核进展”，分别列事实状态、方向研究结论、时间口径、双向解释及待补证据。“因果更新”包含草稿及已完成审核的更新，须看reviewed标记；“市场状态”展示正式市场反馈。完整记录可展开查看。

时间表单按北京时间输入，支持秒。网页填写的判断可获得时间为本次保存时刻，不能利用填写旧公开时间倒推为早已获知。日期级来源保留日期精度，不自动补成零点。

历史研究即使后来完成审核，也不参与2026年当前主导候选选择。回溯统计和历史行情仍在Phase 1.5 / Phase 2，未在本阶段运行。

## CSV批量录入与导出

`data/events`包含每条记录占一行的三张CSV，内容来自Phase 1工程包。导入先验证字段、枚举、引用和日期；错误时整批回滚。相同内容可重复导入，不复制事件；修订内容作为新的研究记录追加。

初始方向五档统一为Strong IM/IM/Neutral/IH/Strong IH；组合渠道明确拆分。工程包与旧研究事件ID通过显式映射归并，不产生两套重复Parent。日内瓦缓和归入关税Parent。

CSV导出保留原始列；另附research_notes.json，包含统一ID、来源、知识时间及人工研究记录。CSV中的Pending和来源标签不替代正式因果审核。

## 数据保护

知识记录只追加，SQLite外键检查保持开启。批量导入前已保存原数据库备份：`database/backups/before_phase1_import.sqlite3`。因果变化后，原方向的市场确认不能直接沿用；相同时间戳的旧State也通过因果阶段编号隔离。

本阶段完成了可用的知识库工具；历史事实、方向与市场状态的审核工作仍需继续，不能将开发完成等同于策略有效。
