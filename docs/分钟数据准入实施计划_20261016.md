# 分钟数据口径与隔离规则实施计划

承接本地行情盘点，仅增加离线研究检查，不接入Event、行情信号、回测或下单。新闻暂停。

当前问题：原始缓存含NUL/短记录及缺失OHLC；同标签并不证明同一时间区间；旧拼接存在两日IH整日缺失，需要追到对应具体合约；时区、供数方与bar定义没有逐段证据。

新增research/minute_data_admission.py、tests/test_minute_data_admission.py及data/minute_data_contract_v0_1.json。检查选择六个旧案例合约、两日缺口对应的四个合约、旧盘点中48个有价格异常的文件；相同文件只读一次。源文件读取前后指纹与盘点指纹核对，漂移则报错，不继续套用旧结论。

输出逻辑文件ID、从1开始的数据记录序号、异常原因、案例日标签交集和具体合约缺口；不输出原始价格或账户路径。含NUL/字段短缺、不可解析时间、非分钟时间、非有限/非正OHLC、OHLC矛盾和重复时间均隔离；相同时间的所有重复行都隔离，不随意留一条。

网格只报告StartLike/EndLike/Other，不作为已核bar_start/end。时区、bar标签、官方日历和行级来源未知仍为null；结构有效仅表示可继续核查，不能成为研究已准入或交易许可。不自动平移、修源、补价或用另一副本填补。

修改既有计算笔记，追加本轮快照重放与可选重跑单元；更新README、交付说明和变更记录。无需数据库迁移，事件库与entry_allowed保持。测试覆盖异常隔离、重复、漂移拒绝、网格与时间语义分离、两腿缺失以及完整日不能越过证据门槛，再运行应用全量测试。

风险：CSV记录序号不是物理行号；不可解析日期的异常不能强行归到某个交易日。日历未认证时只称“有记录的日期”和“诊断网格缺口”。结构检查不覆盖成交可得性或真实报价。公开仅提交汇总、指纹和隔离索引，原行情留本机。
