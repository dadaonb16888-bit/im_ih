资料核对及两张V3卡入库：2026-10-13。页面与交付检查：2026-10-14。事件解释由Codex完成，用户无需填写IM/IH方向。计划见[政策增量与企业路径计划](政策增量与企业路径计划.md)。

## 实现

在原AI研究记录内新增可选`impact_analysis`，旧卡及原流程保持兼容。政策对照记录新事实、旧基线、双方来源、变化类型、实施状态、力度及限制；受益路径记录对象、IM/IH/Both/Unknown、机会、抵消因素、业务或行业代理、观察日期及引用。

- 新政策变化区分NewMechanism、Strengthened、ImplementationDetail、Reaffirmation、Unknown；实施状态区分Intent、Draft、Effective、Unknown。
- 较早公开文件基线与发布方自己的修订说明分别标为EarlierSource和IssuerComparison。日期级资料不能证明同日先后。
- 未找到基线时只能Unknown。引用必须属于该卡已读取或部分读取的来源；行业代理不能标成已核实的企业受益机制，业务和行业暴露不能使用未来日期。
- 导入仍为原事务追加流程；非法表格会回滚来源、研究包及判读。修订使用新ID，同包重放不重复插入。
- 工作台AI判读页增加两张表及Codex相对判断；旧判读按各自版本展示，所有文字转义后呈现。

这些表格是理由和证据，不是新增乘法评分因子，不机械生成Bias、Gain、正式因果或市场State。结构和引用校验不能证明原文真实、政策已实施或推理正确；Codex仍需核原文并填写状态。企业路径可以事前推断，无须等待未来实现利润，但机会不能直接写成已经获得净利润。
